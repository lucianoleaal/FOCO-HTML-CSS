TAGS HTML

Isso é um exemplo de algumas tags HTML que você pode usar para estruturar seu conteúdo. Aqui estão algumas delas:

  • <h1> até <h6>: Usadas para criar títulos e subtítulos, sendo <h1> o mais importante e <h6> o menos importante.
  • <p>: Usada para criar parágrafos de texto.
  • <a>: Usada para criar links para outras páginas ou sites.
  • <img>: Usada para inserir imagens na página.
  • <ul> e <ol>: Usadas para criar listas não ordenadas e ordenadas, respectivamente.
  • <li>: Usada para criar itens de lista dentro de uma lista.
  • <div>: Usada para agrupar elementos e aplicar estilos ou scripts a eles.
  • <span>: Usada para aplicar estilos a partes específicas do texto dentro de um elemento.
